# الاختبارات — tests/

فاضي حاليًا عن قصد — لا تُنشئي اختبارات وهمية قبل ما تحتاجينها فعليًا.

## لما تحتاجين تضيفين اختبارات (مستقبلًا)

**للـ backend (اختبار الـ API):**
```
tests/
└── backend/
    └── auth.test.js     ← مثال: يتحقق إن /api/auth/register يرفض بريد مكرر،
                             وإن /api/auth/login يرفض كلمة مرور غلط...
```
أدوات مقترحة: `jest` + `supertest`.

**للـ frontend (اختبار الواجهة):**
```
tests/
└── frontend/
    └── auth-flow.spec.js  ← مثال: يفتح صفحة الدخول، يعبّي النموذج، يتأكد من التحويل الصحيح
```
أدوات مقترحة: `Playwright` أو `Cypress`.

ابدئي بإضافة أول ملف اختبار فعلي لما يصير عندك منطق مهم يستاهل حماية من الأخطاء المستقبلية (مثل نظام الحسابات الحالي في `backend/server.js`).
