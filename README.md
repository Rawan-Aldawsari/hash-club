# موقع نادي هاش (Hash Club)

هذه النسخة النهائية تستخدم **تسجيل حساب جديد وتسجيل الدخول بالبريد الإلكتروني وكلمة المرور فقط**.

- لا يوجد تسجيل عبر Google أو GitHub أو LinkedIn.
- لا توجد استعادة كلمة المرور عبر البريد الإلكتروني.
- لا تحتاجين إلى SMTP أو OAuth.
- الحسابات وكلمات المرور تُحفظ في MySQL، وكلمات المرور تكون مشفرة.

## التشغيل

1. شغّلي **MySQL** من XAMPP.
2. افتحي phpMyAdmin وأنشئي قاعدة بيانات باسم `hash_club` إذا لم تكن موجودة.
3. من داخل مجلد المشروع شغّلي:

```bash
cd backend
npm install
npm start
```

4. افتحي الموقع من المتصفح على:

`http://localhost:3000`

> مهم: لا تفتحي ملف HTML مباشرة بالنقر عليه، لأن تسجيل الحساب وتسجيل الدخول يحتاجان إلى الخادم.

## إعداد قاعدة البيانات

الخادم ينشئ جدول المستخدمين تلقائيًا عند التشغيل. وإذا أردتِ تشغيل بقية الوظائف وقواعد بيانات صفحات الموقع، استوردي الملف `database/schema.sql` في phpMyAdmin.

## مشكلة Foreign Key السابقة

تم تعديل تشغيل الخادم بحيث لا تتوقف عملية التشغيل بسبب خطأ `Foreign key constraint is incorrectly formed` الذي ظهر سابقًا.
